# Photos go here

Drop each photo in this folder using the **exact filename** below.
As soon as a file exists, it shows up on the site automatically —
no code changes needed. Until then, a labelled placeholder is shown.

## Notes
- `.jpg`, `.png`, `.jpeg`, `.webp` all work — keep the filename (or update the `src` in `index.html`).
- Portrait photos look best in the framed slots (they use a 3:4 box).
- The cover photo fills the whole first screen.
- To reorder or re-caption, edit the `projects` list near the bottom of `index.html`.
